  • Several video PDFs are formulation prompts without the spoken derivation: transportation, production-inventory, bus scheduling, and ambulance location. The corresponding pages explicitly formulate the stated problem using the preceding modelling methods. No unseen video explanation is claimed.
  • The production-inventory prompt does not specify initial stock. Its page exposes the zero-initial-stock assumption for the numerical interpretation. Bus scheduling uses a repeating daily cycle and makes the midnight wrap-around explicit.
  • week2_video06.pdf, p. 9, informally equates basic variables with nonzero variables. The later degeneracy lesson shows the exception. The pages use basis membership, allowing a basic variable to be zero.
  • week2_video09.pdf, p. 7, says “smallest positive ratio,” but zero ratios are necessary for the degeneracy example. Minimum-Ratio Test uses a strictly positive denominator and permits a zero ratio.
  • week2_practice08.pdf, p. 2, prints inequalities after adding slack variables. An augmented equality form needs equality signs. Its final original solution and value are consistent: (0,−5)(0,-5)(0,−5) and −10-10−10.
  • week2_video11.pdf, p. 13, repeats the index in 2x2−x22x_2-x_22x2​−x2​ in an illustrative row. No intended replacement index is guessed; the surrounding surplus/artificial-variable construction is covered using the unambiguous examples.
  • The two-phase worked example has no zero-valued artificial variable left basic. The page flags the need for basis cleanup in that situation but does not invent a detailed unprovided cleanup lesson.
  • week2_practice01.pdf, part (c), is already an unbounded example, so Unbounded Linear Program is tagged week 2 even though the tableau criterion is taught in week 3. Unbounded feasible region alone is not a sufficient explanation.

Uncertainties, Corrections, and Deliberate Omissions¶

  • The course explicitly defines a path by distinct edges, rather than distinct vertices. Path preserves this convention and explains the common alternative word “trail.” Its cycle/tour definition follows that convention. CPP tours may repeat original edges, so that context is distinguished explicitly.
  • Connectedness is defined for the undirected setting used in the introductory examples; no unprovided strong/weak directed connectivity taxonomy is introduced.
  • The unnamed Euler cycle-splicing method is given the searchable alias “Hierholzer's algorithm.” The shortest-path procedure is given the alias “Dijkstra's shortest path algorithm,” and the augmenting-path method the alias “Ford-Fulkerson method.” These identify the actual taught procedures; no alternative implementations or complexity theorems are added.
  • MST examples, Euclidean coordinates, Euler bridge diagrams, CPP pairing costs, shortest-path labels, and flow/residual directions were checked against the PDFs. Diagram-based practice exercises are mapped to their concept pages rather than recreated as independent generic network pages.
  • The CPP matching model pairs the odd vertices without a bipartition. It is kept separate from the later bipartite assignment model.
  • Residual edges have separate directional capacities even though the video draws a single line with two labels. Residual Network makes this explicit.
  • The augmenting-path examples have integer capacities. Finite termination is stated for that setting; no unsupported arbitrary-real-capacity guarantee is added.
  • The max-flow/min-cut theorem, directed CPP variants, negative-edge shortest paths, and minimum-cost flow are not taught in the supplied material and are omitted.
